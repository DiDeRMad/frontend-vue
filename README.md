# Super Puper Online Game (Skeleton)

Этот репозиторий — минимальный каркас для онлайн-игры на Node.js и Socket.io. Подключайтесь с нескольких браузеров и наблюдайте, как квадраты игроков перемещаются в реальном времени.

## Запуск

1. Установите Node.js (v18+ рекомендуется).
2. Установите зависимости:

```bash
cd server
npm install
```

3. Запустите сервер:

```bash
npm start
```

4. Откройте браузер по адресу `http://localhost:3000`. Подключитесь со второго окна/устройства, чтобы увидеть мультиплеер.

## Структура проекта

- `server/` — сервер Express + Socket.io, хранит состояние игроков.
- `client/` — статические файлы (HTML/JS/CSS). Пока что это одна страница с канвасом.
